# AI Database Architect 功能路线图

> 由用户确认的功能清单（2026-08-16 记录），后续开发以此为基准。

## 已确认功能

### 1. ER 概念模型转换
- 概念模型画布：实体、属性、联系（Chen 记法）
- 一键转换为逻辑模型：M:N 拆中间表、1:N 外键下沉、1:1 合并/外键、弱实体处理、多值属性拆表
- 每条转换规则附理由说明，转换结果直接进入现有 ER 画布

### 2. MCP Server
- 让 Cursor / Claude Code 等 AI 编程工具通过 MCP 读取数据库 Schema、ER 图、关系
- 只读工具：列出表、查看表结构、查关系、导出 ER 图、Schema 问答
- 复用现有 FastAPI 后端，前端基本不动
- 传输选型：本地工具用 stdio（默认）；需要 HTTP 时用 Streamable HTTP（单 /mcp 端点），不用已废弃的 SSE 传输

### 3. AI 一键补齐注释 → 数据字典
- 基于表名、字段名、类型、关系批量生成中文注释
- 逐条确认后写回数据库（ALTER ... COMMENT / COMMENT ON）或直接导出
- 数据字典导出格式：Word / PDF / Excel / Markdown

### 4. Schema 版本时间线 + 变更对比
- 快照 diff：表/字段增删改高亮、变更摘要
- 多环境对比（dev/test/prod 漂移检测）
- 可选附加：变更影响范围、ALTER 脚本

### 5. AI 架构评审 + 规则体检
- 规则层：命名大小写、单复数、varchar vs text、无主键表、FK 无索引、类型不兼容外键、注释缺失率、保留字、冗余索引等，每条带修复建议
- AI 层：范式分析、字段冗余、业务建模合理性、设计改进建议
- 输出分级报告（致命/警告/建议）并可导出

### 6. 全画布截图导出 PNG/JPEG/SVG

### 7. SQL 血缘 / 影响分析
- 粘贴或导入 SQL → 解析表依赖（sqlglot 等解析器）
- 血缘关系叠加到 ER 图；选中表 → 高亮依赖它的查询与下游表
- 与版本对比互补：版本对比回答"结构变了什么"，血缘回答"变了影响谁"

### 8. 智能测试数据生成器
- 基于类型、长度、约束、注释、枚举值、外键关系生成符合业务语义的中文测试数据
- 保证外键完整性、支持自引用表、可选 PII 清洗
- 输出 INSERT 脚本或直接写入数据库

### 9. 业务域自动聚类 + 双层 ER 视图
- 基于外键关系图做社区聚类（Louvain/连通域），自动划分业务域
- AI 为每个域起名并生成一句话说明
- 概览层（表名 + 域分组 + 域间关系）→ 详情层（域内完整表结构）

### 10. 敏感数据识别器（自动标记 GDPR/隐私字段）
- 基于字段命名、注释、类型 + 可选数据抽样，识别手机号、身份证、邮箱、密码、银行卡、token、地址等敏感字段
- 自动标记风险级别，输出合规报告与建议措施（加密/脱敏/最小化），对标 GDPR / 个保法（PIPL）
- 支持抽样验证（只读、可配置采样行数）

### 11. 一键生成课程设计/毕设版"数据库设计说明书"
- 章节模板：需求分析、概念结构设计、逻辑结构设计、物理设计、规范化分析、数据字典、总结
- 自动装配已确认功能产出：概念模型图、逻辑模型、数据字典、ER 图图片
- 导出 Word / PDF / Markdown

### 12. DDL / DBML 导入
- 支持粘贴 DDL（CREATE TABLE 语句）或导入 DBML 文件
- 无需连接数据库即可完成建模，进入现有 ER 画布
- 与 Schema 同步互为补充：有库连库，无库贴 DDL/DBML

## 候选功能（待确认）

### 学生 / 教学方向
- 范式规范化分析：1NF→BCNF 自动检查 + 无损分解建议（教材、考试、课程设计刚需）
- 示例项目模板库（图书管理、学生选课、酒店管理等经典课程设计场景，一键导入）
- 基于当前 Schema 生成 SQL 练习题 + 自动批改（复习与教学场景）
- 英文/双语数据字典导出（毕设英文材料、国际化团队）

### 纵向扩展（把学生/教学工作流做深）
- 完整课设/毕设文档套件：开题报告、需求分析、设计说明书、答辩 PPT 大纲、实验报告（同一份项目数据多文档联动生成）
- 文档与 Schema 版本绑定：模型变更后一键重新生成文档并标记变更章节
- 老师批改模式：布置题目、接收学生项目文件、ER 图/规范化批改、进度统计（横向到教学平台）

### 横向扩展（拓宽产品覆盖面）
- 数据库类型扩展：SQLite（学生实验）、SQL Server / Oracle（企业）、国产数据库（达梦、人大金仓、OceanBase、openGauss，政企市场）
- DBML / draw.io / PlantUML 导出
- Git 集成：模型文件入 Git，配合版本对比做历史 diff
- VSCode 插件 / CLI 模式：命令行快速导出文档、执行体检
- 只读文档分享：发布为网页版数据字典（dbdocs 模式，可自托管）

### 通用方向
- 项目文件导入/导出（.adb 备份与分享，便于教师分发模板）
- 打开应用时自动检测 Schema 漂移并提醒
- 命名归一化建议（同义不同名字段检测 + 重命名映射表）

### 新发现候选（第二轮调研 2026-08-16）
- MCP 安全层：只读保护 + PII 字段脱敏 + 审计日志（参考 safedb-mcp / proxy-monster / Bytebase）——让已确认的 MCP Server 变成"安全版"
- 慢查询分析 + AI 索引顾问：读取 pg_stat_statements / performance_schema / 慢查询日志，AI 给出优化建议（参考 dexter / mcp-db-analyzer / QueryGrade）
- 一键生成 CRUD 后端/管理后台：从模型生成 FastAPI/Express 接口 + 简单管理界面（参考 revolve / faucet / autoapi）——课设/毕设"能跑的系统"刚需
- Schema-as-code CI 集成：lint 报告输出 SARIF，GitHub PR 自动评论（参考 skeema / squawk / scythe）
- 本地数据目录 + 术语表：跨项目检索、术语定义、标签分类（DataHub 的轻量个人版）
- 表/字段评论批注：项目内协作注释，老师批改模式的基础（参考 SchemaLens / ChartDB / erd-editor）

### 新发现候选（第三轮调研 2026-08-16，偏工程/交付方向）
- 交互式 HTML 知识库导出：单文件、可搜索的数据字典 + 可点击 ER 图 + 关系说明，双击即用（参考 erdscope / SchemaSpy）
- 数据字典 Excel 双向同步：导出 Excel 供业务/测试人员补注释，改完导回更新模型并写回数据库（暂无成熟先例，蓝海）
- ORM 代码导入 + 一致性检查：从 SQLAlchemy / Django / Prisma / Rails 模型反向建图，并对比代码与真实库的漂移（参考 erdscope）
- AI 变更解读：版本对比（已确认功能 4）的 diff 自动生成人话总结："这次改动把订单表拆成两张表，影响支付查询"
- 双库兼容性/迁移风险评估：MySQL ↔ PostgreSQL 类型映射、特性差异（JSON vs JSONB、AUTO_INCREMENT vs SERIAL）、风险清单报告（兑现 README 的"设计一次，双库落地"承诺，但不生成 DDL）
- Schema 指纹 + 漂移自动提醒：计算 schema 指纹，应用启动/定时自动比对，漂移即生成变更报告（配合功能 4）
